<read_first>

- backend/routers/data.py
</read_first>
<action>
1. Create `backend/routers/forecast.py` with APIRouter (prefix="/api", tags=["forecast"]):
   - GET endpoint `/forecast`:
     - Query parameters: `item_id` (required string, e.g. `item_id: str = Query(...)`).
     - Loads `store.future_window` and filters by `item_id`.
     - Validates item existence against `store.items` (raise 404 if not found).
     - Calls `model_store.predict(item_future_df)` to get `p10`, `p50`, `p90`.
     - Combines future window features (`date`, `sell_price`, `supplier_cost`, etc.) with model predictions (`p10`, `p50`, `p90`) into a structured list of dicts.
     - Strictly ensures `true_demand` is never present or exposed.
2. Register `forecast.router` in `backend/main.py`.
</action>
<acceptance_criteria>

- Router successfully included in `backend/main.py`.
</acceptance_criteria>
