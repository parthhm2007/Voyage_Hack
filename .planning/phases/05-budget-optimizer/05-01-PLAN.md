  <action>
    Create `backend/routers/optimize.py` with an APIRouter prefix `/api` and tags `["optimize"]`.
    Define endpoint: `GET /api/optimize` accepting query parameters:
    - `total_budget`: float (required, e.g. 500000.0)
    - `start_date`: Optional[str]
    - `end_date`: Optional[str]
    
    Logic details:
    1. Load store (`store.load()`).
    2. For each item in `store.items`:
       - Compute unconstrained newsvendor optimal quantity and expected profit across the date window (reusing the newsvendor calculation logic).
       - Determine item unit cost $c_i$, sell price $p_i$, salvage value $s_i$, and total unconstrained cost $C_i = c_i \times Q^*_{total}$.
       - Compute expected profit $P_i$ and marginal ROI (Expected Profit / Cost or Marginal Profit per Rupee).
    3. Greedy Budget Allocation Algorithm:
       - Sort items by descending marginal ROI (or expected profit per rupee).
       - Allocate budget to items in priority order until `total_budget` is exhausted.
       - If an item's unconstrained cost fits within remaining budget, allocate full $C_i$. Otherwise, allocate remaining budget proportionally or fractionally to buy $Q$ units.
    4. Compute portfolio totals: `allocated_budget`, `total_expected_profit`, `portfolio_roi`, and list of item allocations (`item_id`, `item_name`, `item_type`, `destination`, `allocated_budget`, `units_purchased`, `expected_profit`, `roi`).
    5. Register `optimize.router` in `backend/main.py`.
  </action>
