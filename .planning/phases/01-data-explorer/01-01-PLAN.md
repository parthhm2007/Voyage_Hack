## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client Browser → FastAPI REST API | Untrusted query parameters crossing into pandas filtering operations. |
| FastAPI Backend → `./data/synthetic/` CSV files | Read-only file system access boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `GET /api/history` | mitigate | Explicitly drop `true_demand` column from DataFrame before JSON serialization. |
| T-01-02 | Tampering / Path Traversal | CSV file loader | mitigate | Hardcode path to `./data/synthetic/` and prevent user-controlled file paths. |
| T-01-SC | Tampering | pip package installs | mitigate | Slopcheck verified trusted PyPI packages (`fastapi`, `uvicorn`, `pandas`, `pydantic`). |
</threat_model>
