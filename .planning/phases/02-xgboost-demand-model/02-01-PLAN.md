<action>
Create `backend/train_models.py` which:
1. Loads `data/synthetic/daily_history.csv` using pandas, sorting by `date`.
2. Engineers features per item_id:
   - Temporal: `day_of_week`, `month`, `day_of_month`, `is_weekend`
   - Lag: 7-day lagged `bookings` and `searches`
   - Rolling: 7-day rolling mean for `bookings` and `searches`
   - Commercial: `sell_price`, `supplier_cost`, `lead_days`, gross margin (`sell_price - supplier_cost`)
   - Strictly excludes `true_demand`.
3. Performs chronological 80/20 train/validation split based on date.
4. Trains three XGBoost Regressors (`objective='reg:quantileerror'`) with alpha values `0.10`, `0.50`, and `0.90` predicting `bookings`.
5. Evaluates and prints validation pinball loss for each quantile.
6. Creates `backend/models/` directory and saves trained model artifacts (e.g. `model_p10.json`, `model_p50.json`, `model_p90.json` or joblib files).
7. Run `python backend/train_models.py` to generate the models.
</action>
<acceptance_criteria>
- `backend/train_models.py` successfully runs and exits with status 0.
- Model artifacts (`model_p10.json`, `model_p50.json`, `model_p90.json` or equivalent joblib/json files) are successfully created in `backend/models/`.
- Training log outputs validation pinball losses for P10, P50, and P90.
- `true_demand` is not used in feature matrix or target.
</acceptance_criteria>
